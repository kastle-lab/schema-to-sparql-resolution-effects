# Competency Questions

This directory contains competency question lists used as SPARQL generation tasks for each schema or knowledge graph configuration.

## Directory and File Overview

* `core_scholar_rich.txt` — Competency questions for the rich Core Scholar schema.
* `core_scholar_shallow.txt` — Competency questions for the shallow Core Scholar schema.
* `kwg.txt` — Competency questions for the KnowWhereGraph schema.
* `kwg_lite.txt` — Competency questions for the KWG-Lite schema.
* `README.md` — Readme file for this directory.
