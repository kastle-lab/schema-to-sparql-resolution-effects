# SPARQL Prompt Assets

This directory contains JSON assets used to fill SPARQL prompt templates with examples and reasoning scaffolds.

## Directory and File Overview

* `core_scholar_rich.json` — Prompt asset examples for the rich Core Scholar schema.
* `core_scholar_shallow.json` — Prompt asset examples for the shallow Core Scholar schema.
* `default.json` — Generic fallback SPARQL prompt asset.
* `kwg.json` — Prompt asset examples for the KnowWhereGraph schema.
* `kwg_lite.json` — Prompt asset examples for the KWG-Lite schema.
* `README.md` — Readme file for this directory.
