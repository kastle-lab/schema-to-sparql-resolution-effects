# Results

This directory contains SPARQL generation and evaluation outputs.

## Directory and File Overview

* `batch_results_prediction-model-2026-05-01T20_10_27.865167Z_predictions.jsonl` — Raw JSONL batch prediction output from a model run.
* `sparql_evaluation_results.csv` — Per-query evaluation results in CSV format.
* `sparql_evaluation_results.jsonl` — Per-query evaluation results in JSONL format.
* `sparql_evaluation_summary.csv` — Aggregated evaluation summary in CSV format.
* `sparql_evaluation_summary.jsonl` — Aggregated evaluation summary in JSONL format.
* `README.md` — Readme file for this directory.
