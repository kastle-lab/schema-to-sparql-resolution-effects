# Prompts

This directory contains Python prompt template modules used to assemble LLM requests for SPARQL generation.

## Directory and File Overview

* `sparql_0_shot.py` — Zero-shot system and user prompt templates.
* `sparql_cot.py` — Chain-of-thought-style prompt template that asks the model to reason internally before returning one query.
* `sparql_few_shot.py` — Few-shot system and user prompt templates, including slots for examples.
* `README.md` — Readme file for this directory.
